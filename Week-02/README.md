# Week 2 — Data Collection, Preparation & Cleaning

This package contains the implementation artifacts for Week 2 of the Agriculture & Agribusiness Data Science internship.

## Contents

- `notebooks/Week_2_Data_Collection_and_Cleaning.ipynb` — reproducible data profiling, cleaning, validation and transformation workflow.
- `data/raw/` — preserved Week 1 DES analytical extract used as the actual Week 2 working source.
- `data/processed/` — generated clean analytical dataset.
- `data/reference/` — crop mapping, state/district mapping templates and cleaning rules.
- `docs/` — data dictionary and official source register.
- `scripts/` — reusable quality-report script.
- `outputs/quality_reports/` — validation results.

## Scope

Week 2 focuses on creating a repeatable pipeline before integrating district/state APY, climate and market datasets. The notebook intentionally does not claim that live Agmarknet or climate records have already been collected.

## Reproducibility

Open the notebook from `Week-02/notebooks/` and run the cells from top to bottom. The relative paths assume the repository structure is unchanged.
